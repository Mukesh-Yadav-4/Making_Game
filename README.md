\# ⚡ Neon Escape



A fast-paced browser survival game built with \*\*HTML, CSS, and JavaScript\*\*.



\## 🎮 Play the Game



\*\*\[▶ Play Neon Escape]https://mukesh-yadav-4.github.io/Making_Game/



\## 🕹️ About



Neon Escape is a neon-themed survival game where you dodge incoming hazards, collect energy, use defensive abilities, and survive increasingly difficult encounters.



\### Features



\* ⚡ Progressive difficulty

\* 👾 Boss encounters

\* 🔫 Weapons and attacks

\* 🛡️ Defensive mechanics

\* 💎 Collectible energy orbs

\* 🎵 Dynamic audio

\* 🏆 Local high scores

\* 🎚️ Easy, Normal, and Hard difficulty modes

\* ⏸️ Pause and restart systems



\## 🎮 Controls



| Action  | Controls           |

| ------- | ------------------ |

| Move    | `←` `→` or `A` `D` |

| Pause   | `P`                |

| Restart | `R`                |



\## 🛠️ Built With



\* HTML5

\* CSS3

\* JavaScript

\* HTML5 Canvas

\* Web Audio API
